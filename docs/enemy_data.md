## Placement lists

Each level has five parallel arrays (pointer tables lo/hi at 08:81FE-8294 `spawnXPageLo` … `spawnTypeHi`), indexed by the enemy number and sorted by X:
X page (`ptr_74`), X low (`ptr_72`), Y page (`ptr_78`), Y low (`ptr_76`), enemy type (`ptr_7A`). The list ends with X=$FFFF, Y=$FF, type $FF.
Enemies are spawned when they come near the scroll position (`totalEnemies`/`ram_009F` are the window indices into the list).

## Enemy types (105 entries)

`enemyTypeTable` (08:8442) + `enemyStatTable` (08:85E6), 4 bytes each, indexed by the type number. `SpawnEnemy` copies them to the object slot:

- type table: `objFlags`, `objKind` (= `objId`, selects the AI in `enemyAILo/Hi`), `objAnim`, `objArr_0440`;
- stat table: `objLife` (also `objArr_04A0`, the maximum), `objSpriteAir`, `objSpriteDown`, unused.
